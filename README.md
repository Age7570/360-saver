# All-in-One Social Media Downloader API

A production-ready Node.js API built using Express.js to fetch direct downloadable media URLs from Instagram, TikTok, and YouTube. Optimized for deployment on Pxxl Africa.

## 🚀 Deployment to Pxxl Africa

1. **Initialize Git & Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   # Create a repository on GitHub and link it:
   git remote add origin <your-github-repo-url>
   git branch -M main
   git push -u origin main
   ```

2. **Deploy on Pxxl**:
   - Log into your [Pxxl Africa](https://pxxl.app/) Dashboard.
   - Connect your GitHub Account.
   - Select this repository.
   - Leave the **Build Command** blank or set to `npm install`.
   - Set the **Start Command** to `npm start`.
   - Click **Deploy**.

## 🛠️ Local Development

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Test endpoints via Postman or cURL.
